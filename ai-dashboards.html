07 Same use case · different algorithms

Detecting an earthquake: which algorithm?

Same seismic signal — with a noise spike and a real earthquake. Switch the method and watch what each one flags.

Simulated signal
MethodHow it decidesTool example
STA/LTAShort-term ÷ long-term average of amplitude crosses a threshold. No training. Sensitive to noise & threshold.ObsPy (Python)
Forecast band / spike-and-dipLearns the normal range; flags values outside it. Fast, built into streaming tools.Azure Stream Analytics (SpikeAndDip, ChangePoint) · Grafana ML
Deep learning (PhaseNet)Neural network trained on labelled waveforms; outputs P-wave, S-wave and noise probabilities.PhaseNet (Python, open source)
Lesson: there is no “best” algorithm — only the best fit for speed, accuracy, data and skills. Often you run two and compare.

11 Wrap-up

Key takeaways & a 60-second quiz

1
From “what happened” to “what next”

AI adds detection, prediction and explanation on top of real-time data.

2
Component = Data + Algorithm + Tool

Match the data layer (real-time → strategic) with the right algorithm and engine.

3
Many algorithms, many tools

Anomaly, forecasting, association, classification, segmentation, conversational agents.

4
Build it as a loop

KPIs → data → model → design → deploy → monitor & fine-tune — with humans in the loop.
